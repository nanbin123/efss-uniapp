### 平台简介： 
                              
uniapp手机版，支持微信小程序与钉钉版本，它是一个管理软件，是一个专门用于家具销售行业的销售管理软件。适用于以家具销售为主的各类型公司，如家具销售公司、专卖店等，它可以全面管理订单、采购、销售、库存、资金往来等各项工作。导购员可以用它开单，仓管员可以用它入库、出库，经理出差在外也可随时看报表，使用户摆脱了电脑的束缚，极大地提高了工作效率。
